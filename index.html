What is AI?

AI (artificial intelligence) is a set of techniques that let computers learn patterns from examples and make predictions or help with tasks. Think of it as a tool that helps automate thinking-like steps.

Real-world example: A photo app that groups your vacation pictures by location or a chat assistant that helps you draft an email.
Try it yourself: 
Prompt: "Summarize this paragraph in one sentence."
Common mistakes:
  • Expecting perfect answers — AI gives likely answers based on data.
  • Using vague prompts — clearer instructions get better results.

Mini challenge: Write one sentence describing where you've seen AI in daily life.

How AI works

AI systems learn from examples (data). A model looks at many examples and learns patterns; then it can make predictions on new inputs. There are different types of models for text, images, and more.

Real-world example: A spam filter learns from many labeled emails to spot likely spam.
Try it yourself: 
Activity: Think of 5 examples of "good" vs "bad" answers for a task — this is how labeled data helps.
Common mistakes:
  • Confusing correlation for causation — AI finds patterns, not always reasons.

Mini challenge: Name one place you would use data to teach an AI (e.g., images of cats vs dogs).

Prompts

Prompts are the instructions you give to AI. A clear prompt explains the goal, gives context, and shows the type of output you want.

Real-world example: "Write a 3-line friendly explanation of X for beginners" is clearer than "Explain X".
Try it yourself: 
Prompt: "List 3 simple projects a beginner can build with HTML and AI."
Common mistakes:
  • Being too brief — include examples and the desired format.
  • Giving contradictory instructions — keep it simple and consistent.

Mini challenge: Rewrite a vague prompt to be specific and test the difference.

ChatGPT

ChatGPT is a conversational AI that can answer questions, draft text, and help with ideas. It's tuned for dialogue and can be used to explore topics step-by-step.

Real-world example: Ask ChatGPT to explain a concept in simple language or to draft an email template.
Try it yourself: 
Prompt: "Explain recursion in simple terms with an everyday example."
Common mistakes:
  • Trusting the output without checking facts — always verify important details.

Mini challenge: Ask ChatGPT to rewrite a short paragraph in a friendlier tone.

GitHub Copilot

GitHub Copilot is a coding assistant that suggests whole lines or blocks of code as you type. It speeds up repetitive tasks and gives examples to learn from.

Real-world example: Copilot can suggest a function body when you write a comment describing what the function should do.
Try it yourself: 
Activity: In your editor, write a comment describing a small function, then see what suggestions appear.
Common mistakes:
  • Using suggested code without understanding it — always read and test the code.

Mini challenge: Accept a suggested line and explain what it does in one sentence.

Building websites with AI

AI can help plan layouts, write content, and generate assets. Use it as a helper to speed up routine tasks while you focus on design choices.

Real-world example: Generate a homepage structure and then refine it manually to match your style.
Try it yourself: 
Prompt: "Suggest a simple 3-section homepage layout for a personal portfolio."
Common mistakes:
  • Relying on AI output without customizing it — always adapt suggestions to your needs.

Mini challenge: Use an AI to draft the first paragraph of your homepage, then edit it to sound like you.

HTML basics

HTML (HyperText Markup Language) gives structure to a page using tags like <h1> for headings and <p> for paragraphs.

Real-world example: An article page uses <h1> for the title, <h2> for sections, and <p> for paragraphs.
Try it yourself: 
<h1>My Project</h1>
<p>A short description of my project.</p>
Common mistakes:
  • Using tags for style instead of structure (use CSS for styling).

Mini challenge: Create a small HTML file with a heading and two paragraphs.

CSS basics

CSS (Cascading Style Sheets) controls colors, spacing, fonts, and layout. It keeps content and presentation separate.

Real-world example: Use CSS to center a profile picture and add spacing between sections.
Try it yourself: 
h1 { color: #2869ff; }
p { line-height: 1.6; }
Common mistakes:
  • Using inline styles instead of keeping CSS in one place.

Mini challenge: Change the font size of a heading and observe the result.

JavaScript basics

JavaScript adds interactivity: respond to clicks, change content, and work with data in the browser.

Real-world example: A button that shows a popup or loads more items without reloading the page.
Try it yourself: 
document.getElementById('hello').addEventListener('click', ()=> alert('Hello'));
Common mistakes:
  • Not waiting for the page to load before selecting elements — use DOMContentLoaded.

Mini challenge: Make a button that changes a paragraph's text when clicked.

GitHub & GitHub Pages

Git helps track changes to files. GitHub hosts repositories online. GitHub Pages lets you publish a website from a repository for free.

Real-world example: Publish your portfolio by pushing files to a repository and enabling Pages in settings.
Try it yourself: 
Create a repo, add index.html, and enable GitHub Pages in the repo settings.
Common mistakes:
  • Not committing changes often — commit small steps with clear messages.

Mini challenge: Create a repository and add a README describing your project.

Debugging

Debugging is the process of finding and fixing errors. Use the browser console, add console.log statements, and test small changes to isolate problems.

Real-world example: A missing semicolon causes an error — the console points to the file and line.
Try it yourself: 
Open DevTools (F12) and check the Console for errors during page load.
Common mistakes:
  • Guessing the fix — read the error and reproduce the problem step-by-step.

Mini challenge: Break a line intentionally and fix it using the console message clues.

FAQ

Frequently asked questions

Short answers to common beginner questions.

What is AI?

AI (artificial intelligence) is a set of techniques that let computers learn patterns from examples to make predictions or help with tasks—like recognizing images or summarizing text.

Do I need coding experience?

No. You can start with basic lessons and hands-on projects. Coding helps for deeper work, but many beginner activities require only small edits to examples.

Is GitHub Copilot free?

GitHub Copilot often offers trials but is typically a paid service for full access. Check GitHub's official page for current pricing and student offers.

Can AI help me build websites?

Yes. AI can suggest layouts, generate copy, and create code snippets. Treat its output as a helpful starting point and review or customize it.

How long does it take to learn AI?

Basics can be learned in days to weeks with consistent practice. Building confidence takes months; real expertise takes longer and practice on real projects.

Can I make money with these skills?

Yes. Beginners can offer simple services, build a portfolio, or find entry-level roles. Start with small projects and gradually take on paid work as you gain confidence.

What should I learn first?

Begin with the basics: simple HTML, CSS, and how AI prompts work. Try small projects combining those skills to learn quickly by doing.

What if I make mistakes?

Mistakes are normal and helpful—debug, ask questions, and iterate. Use browser DevTools, read errors, and test small changes to learn faster.
